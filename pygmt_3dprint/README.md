# 從 PyGMT 地形圖到 3D 列印檔

先看教學影片（3 分鐘，中文旁白與字幕）：[`artifacts/23-pygmt_stl_teaching_video.mp4`](../artifacts/23-pygmt_stl_teaching_video.mp4)，網頁版嵌在 [`pygmt-3dprint.html`](../pygmt-3dprint.html)。

## 課堂怎麼排

三節課各 50 分鐘已經排滿。這份實作是另外一節，三條路選一條。

| 路線 | 什麼時候用 | 這一節做什麼 |
|---|---|---|
| A. 沒有印表機 | 大多數課堂 | 約 25 分鐘。看影片、看範例圖、用下面步驟 4 的數字回答步驟 7。不裝軟體 |
| B. 有一台印表機 | 老師前一晚印好 | 全班共用一個模型。範例是 140 × 162.5 × 26 mm，加上 brim 要確認放得進列印床，而且大約要印一整晚。想小一點：`WIDTH_MM = 80`、`RELIEF_MM = 13`（誇大仍約 10 倍，約 80 × 93 × 17 mm，通常兩到三小時）。改了尺寸就不要再對網頁上的 18.7 mm |
| C. 電腦教室已裝好 conda | 課前裝完 | 只跑步驟 3 和 4，解析度用 `05m`。步驟 6 留到課後 |

步驟 1 的 `conda create` 第一次常常要 20–40 分鐘，不要在這一節從安裝開始。這門課的地圖實作用 Colab，Colab 沒有 GMT，也切不了片。

走路線 A 的人看完影片，用步驟 4 表格裡的臺灣範例回答步驟 7，不必往下跑程式。
走路線 C 的人照下面的順序做。每一次只做一步，看到「檢查」裡的結果再進下一步。做完會得到兩樣東西：一張北方朝上的地形圖（PNG），和一個單位是公釐、可以直接切片的模型（STL）。

預設範圍是臺灣和旁邊的海溝。第二個範圍是巽他海峽與喀拉喀托之子。
學生只需要改 `settings.py`。

## 步驟 1　安裝（課前，不在這一節做）

PyGMT 需要 GMT 本體。用 conda-forge 一次裝齊，不要只下 `pip install pygmt`。

還沒有 conda 的話，先裝 [Miniforge](https://github.com/conda-forge/miniforge)。

```bash
conda create -n pygmt -c conda-forge python=3.12 pygmt netcdf4
conda activate pygmt
cd pygmt_3dprint
python -c "import pygmt; print(pygmt.__version__)"
```

Windows 請開 **Anaconda Prompt** 再貼上同樣的指令。

**檢查：** 印出一個版本號，沒有紅字。

## 步驟 2　選範圍

打開 `settings.py`。

1. 維持 `PRESET = "taiwan"`。
2. 第一次把 `RESOLUTION = None` 改成 `RESOLUTION = "05m"`。05 角分比較粗，下載快，用來確認流程。
3. 其餘先不要動。`WIDTH_MM = 140` 是模型的東西向寬度，單位公釐。

**檢查：** 存檔。區域的順序是 `[西, 東, 南, 北]`。

## 步驟 3　畫地形圖

```bash
python 01_plot_topography.py
```

第一次會連到 GMT 資料伺服器，可能要幾分鐘。中斷了就再執行一次，已下載的部分會沿用。

**檢查：**

- 終端機最後寫「完成」，並印出高程的最低、最高值（公尺）。負值是海底。
- 打開 `output/taiwan_relief.png`。
- 指北針朝上，東邊在右。
- 藍色是海，綠到棕色是陸地，色標寫 Elevation (m)。
- 你要能指出海溝（最深的藍）和臺灣本島。

## 步驟 4　做成 3D 列印檔

```bash
python 02_relief_to_stl.py
```

**檢查：** 終端機有一塊「寫進學習單」。把這六個數字抄下來。

| 要抄的 | 意義 |
|---|---|
| 模型尺寸 | 切片軟體裡量到的長寬高必須和這裡一樣，單位公釐 |
| 海平面 | 底座以上幾公釐是 0 公尺。底座是最深的海底，不是海平面 |
| 垂直誇大 | 高度被放大了幾倍。模型上的坡度比真實陡 |
| 若不誇大 | 同樣的水平比例下，高低差只剩幾公釐，印不出來 |
| 封閉：是 | 每條邊正好被兩個三角形共用，切片軟體才修補得了 |
| 檔案 | `output/taiwan_relief.stl` |

方向是 +X 朝東、+Y 朝北。

## 步驟 5　用切片軟體打開

用 Cura、PrusaSlicer 或 Bambu Studio，三個都免費。

1. 匯入 `output/taiwan_relief.stl`。
2. 單位選公釐。尺寸要和步驟 4 的模型尺寸一致，差超過 1 mm 就停下來，不要直接列印。
3. 不要只拉高模型。要改大小就整體等比縮放，垂直誇大的倍數才不會再被你改掉。
4. 底座平貼平台。這是實心塊，斜坡通常不需要支撐。
5. 建議：層高 0.2 mm、填充 10–15%、外壁 3 層、加一圈 brim 幫助黏著。
6. 看第一層：應該是一個完整的長方形，中間沒有破洞。
7. 臺灣範例南北 162.5 mm、東西 140 mm，較長的那一側是南北。讓模型平躺，不要轉成側立。列印完在北側用筆標一個 N。不要假設螢幕上方是北。

**檢查：** 預覽裡看得到海溝是凹下去的、島是凸起來的，而且海平面不是最底層。

## 步驟 6　進階：換成正式解析度，或換一個範圍（課後，不在這一節做）

1. 把 `settings.py` 的 `RESOLUTION` 改回 `None`，再跑一次步驟 3 和步驟 4。解析度改用 02 角分，海岸和海溝會清楚一些，檔案也比較大。
2. 把 `PRESET` 改成 `"sunda"`，執行：

```bash
python 01_plot_topography.py --preset sunda
python 02_relief_to_stl.py --preset sunda
```

在巽他海峽的模型上指出三件事：西南側的海溝、沿蘇門答臘與爪哇的淺水陸架、海峽裡的喀拉喀托。

要做自己的範圍，在 `settings.py` 的 `PRESETS` 加一筆，`region` 一樣寫 `[西, 東, 南, 北]`，然後用 `--preset` 那個名字重跑。

## 步驟 7　回答這四題再交

1. 若不誇大，高低差在模型上是幾公釐？為什麼還是要誇大？
2. 能不能把模型上的坡度當成真實坡度？
3. 臺灣範例有 139728 個三角形（02 角分）。改成 05 角分時，三角形大約變成幾分之一？噴嘴是 0.4 mm 時，為什麼不值得再印更細的網格？（大約六分之一。比噴嘴還密的細節印不出來。）
4. 這個模型上看得到 2026 年 9 月喀拉喀托之子新增的 32.8 公頃陸地嗎？為什麼？

第 4 題的方向：02 角分大約 3–4 公里一格，32.8 公頃不到 1 平方公里，比一格還小。這份網格是區域地形，不是那 25 小時噴出來的火山灰。海溝和島弧是百萬年尺度，新陸地是小時尺度。

## 常見問題

| 現象 | 處理 |
|---|---|
| `ModuleNotFoundError: pygmt` | 忘記 `conda activate pygmt`，或是用 pip 裝的。回到步驟 1 |
| `GMTCLibNotFoundError` | 電腦上沒有 GMT。刪掉環境，用步驟 1 的 conda 指令重裝 |
| 下載停住或逾時 | 再執行一次 `01_plot_topography.py`。快取放在家目錄的 `.gmt` |
| 切片軟體裡的尺寸差了約 25 倍 | 單位被當成英吋。改成公釐 |
| 模型幾乎是一塊平板 | `RELIEF_MM` 太小，或範圍小到沒有高低差。看終端機的「垂直誇大」 |
| 斜坡陡到需要很多支撐 | 把 `RELIEF_MM` 從 22 改小，例如 12，再跑步驟 4。誇大倍數會跟著下降 |
| 警告說單邊點數太多、已抽稀 | 正常。想保留更細的網格就把 `MAX_POINTS` 調大，切片會變慢 |
| 終端機寫「封閉：否」 | 不要拿去列印。把完整的終端機訊息留下來詢問 |
| 模型放不進列印床，或預覽要印很久 | `WIDTH_MM = 80`、`RELIEF_MM = 13`，再跑步驟 4。全班仍只印一個 |
| 想在課堂上從步驟 1 開始裝 | 改走路線 A。這一節用範例圖和步驟 4 的數字 |

## 檔案

| 檔案 | 誰來改 |
|---|---|
| `settings.py` | 學生。範圍、解析度、模型尺寸都在這 |
| `01_plot_topography.py` | 不用改。下載網格、畫 PNG、存 NetCDF |
| `02_relief_to_stl.py` | 不用改。讀網格、算誇大倍數、寫 STL。`--self-test` 會檢查模型是否封閉 |
| `output/` | 程式產生的圖和 STL，不進版控 |
| `example/` | 已經跑好的臺灣與巽他海峽範例（PNG 與 STL），用來對照自己的結果 |

網頁版步驟（含範例圖）：倉庫根目錄的 [`pygmt-3dprint.html`](../pygmt-3dprint.html)。
