從地形圖到 3D 列印 From a PyGMT map to a printable file

用同一份高程網格，先畫出北方朝上的地形圖，再做成單位是公釐、可以切片的 STL。預設是臺灣和旁邊的海溝，第二個範圍是巽他海峽。 One elevation grid becomes a north-up map and then a millimetre STL a slicer can open. The default region is Taiwan and its trenches; the second is the Sunda Strait.

照這個順序做Do it in this order

“Finish the check before you start the next step.”每一步看到檢查結果，再做下一步。

程式在 pygmt_3dprint/。學生只改 settings.py。終端機請先 cd 到那個資料夾。完整純文字版在 pygmt_3dprint/README.md。The scripts live in pygmt_3dprint/. Students only edit settings.py. cd there first. The same steps in Markdown: pygmt_3dprint/README.md.

  1. 1安裝Install

    PyGMT 需要 GMT 本體。用 conda-forge 一次裝齊。pip install pygmt 不會裝 GMT。PyGMT needs the GMT library. conda-forge installs both. pip install pygmt does not.

    還沒有 conda，先裝 Miniforge。Windows 請開 Anaconda Prompt。No conda yet? Install Miniforge. On Windows, use Anaconda Prompt.

    conda create -n pygmt -c conda-forge python=3.12 pygmt netcdf4
conda activate pygmt
cd pygmt_3dprint
python -c "import pygmt; print(pygmt.__version__)"
    檢查 Check

    印出版本號，沒有紅字。A version number prints, and nothing is red.

  2. 2選範圍Choose a region

    打開 settings.py。維持 PRESET = "taiwan"。第一次把 RESOLUTION = None 改成 RESOLUTION = "05m"，用較粗的 5 角分確認流程跑得通。其餘先不要動。Open settings.py. Keep PRESET = "taiwan". For the first run set RESOLUTION = "05m" so the download is small. Leave the rest alone.

    檢查 Check

    已存檔。區域順序是 [西, 東, 南, 北]，單位是度。The file is saved. A region is [west, east, south, north] in degrees.

  3. 3畫地形圖Plot the map

    python 01_plot_topography.py

    第一次會連到 GMT 資料伺服器，可能要幾分鐘。中斷了就再執行一次，已下載的部分會沿用。The first run downloads from the GMT data server and can take a few minutes. If it stops, run it again; finished tiles are cached.

    檢查 Check

    終端機印出高程的最低和最高（公尺）。負值是海底。打開 output/taiwan_relief.png，確認指北針朝上、東邊在右、色標單位是公尺，而且你指得出海溝和臺灣本島。The terminal prints the lowest and highest elevation in metres. Negative numbers are the sea floor. Open output/taiwan_relief.png: north up, east to the right, colour bar in metres, and you can point at the trench and at Taiwan.

  4. 4做成 STLBuild the STL

    python 02_relief_to_stl.py

    程式把最深的海底放在底座上，最高的山再抬高 RELIEF_MM。海平面不是底座。東是 +X，北是 +Y。它也會檢查每條邊是不是正好被兩個三角形共用；不是的話不要拿去切片。The deepest sea floor sits on the base and the highest peak rises RELIEF_MM above that. Sea level is not the base. East is +X, north is +Y. The script also checks that every edge is shared by exactly two triangles.

    檢查 Check

    終端機有一塊「寫進學習單」。把模型尺寸、海平面高度、垂直誇大倍數、封閉是否為「是」抄下來。用 02 角分、寬度 140 mm 時，臺灣這個範圍會接近下面這組數字；你若還停在 05m，三角形會少很多，尺寸和誇大倍數仍應接近。Copy the model size, the sea-level height, the vertical exaggeration and the word 「封閉：是」. At 2 arc-minutes and 140 mm wide, Taiwan comes out close to the numbers below. A 05m grid has fewer triangles; the size and the exaggeration should still be close.

    項目 Item臺灣範例 Taiwan example你要確認的事 What to check
    模型尺寸 Size140.0 × 162.5 × 26.0 mm切片軟體量到的長寬高要一樣，單位公釐
    海平面 Sea level底座以上 18.7 mm底座是深約 6500 m 的海底，不是海面

  5. 5用切片軟體打開Open it in a slicer

    用 Cura、PrusaSlicer 或 Bambu Studio。還沒跑完程式的話，可以先打開範例 STL，熟悉軟體，再用自己做出的檔案取代它。Use Cura, PrusaSlicer or Bambu Studio. If your own file is not ready, open the example STL first, then replace it with yours.

    1. 匯入 STL，單位選公釐。尺寸要和步驟 4 一致，差超過 1 mm 就停下來。Import the STL and set the unit to millimetres. The size must match step 4; stop if it is off by more than 1 mm.
    2. 不要只拉高模型。要改大小就三個方向一起縮，誇大倍數才不會被你再改掉。Do not stretch only the height. Scale all three axes together, or you change the exaggeration.
    3. 底座平貼平台。這是實心塊，斜坡通常不需要支撐。Seat the flat base on the bed. It is a solid block; the slopes usually need no support.
    4. 建議層高 0.2 mm、填充 10–15%、外壁 3 層，並加一圈 brim。Suggested: 0.2 mm layers, 10–15% infill, 3 walls, and a brim.
    5. 第一層應該是一個完整的長方形。看座標軸確認哪一側是北，印完在北側標一個 N。The first layer should be one solid rectangle. Use the axis widget to find north, and mark N on that edge after printing.
    檢查 Check

    預覽裡海溝是凹的、島是凸的，海平面不是最底層。In the preview the trench is a valley, the island is a ridge, and sea level is not the bottom.

  6. 6換成正式解析度，或換範圍Use the finer grid, or another region

    把 RESOLUTION 改回 None，再跑一次步驟 3 和 4。程式會改用 02 角分。接著把 PRESET 改成 "sunda"：Set RESOLUTION back to None and repeat steps 3 and 4. That uses 2 arc-minutes. Then set PRESET to "sunda":

    python 01_plot_topography.py --preset sunda
python 02_relief_to_stl.py --preset sunda
    檢查 Check

    在巽他海峽的圖和模型上指出三件事：西南側的海溝、蘇門答臘與爪哇、海峽的位置。要做自己的範圍，就在 PRESETS 加一筆，region 一樣寫 [西, 東, 南, 北]，再用 --preset 那個名字重跑。On the Sunda figure and model, point to the trench on the southwest side, to Sumatra and Java, and to the strait. For your own area, add an entry under PRESETS with [west, east, south, north] and rerun with that --preset name.

  7. 7回答這四題再交Answer these four before you hand it in

    1. 若不誇大，高低差在模型上是幾公釐？為什麼還是要誇大？Without exaggeration, how many millimetres tall is the relief? Why exaggerate anyway?
    2. 能不能把模型上的坡度當成真實坡度？Can you treat a slope on the model as the real slope?
    3. 解析度從 05m 改成 02m，三角形大約變多幾倍？噴嘴是 0.4 mm 時，是不是愈細愈值得印？From 05m to 02m, by about what factor does the triangle count grow? With a 0.4 mm nozzle, is finer always worth printing?
    4. 這個模型上看得到 2026 年 9 月喀拉喀托之子新增的 32.8 公頃嗎？為什麼？Can you see the 32.8 hectares added at Anak Krakatau in September 2026? Why?
    寫完再展開Open after you have written
    1臺灣範例是 2.22 mm。水平把 600 公里縮進 140 mm，同樣比例下約 10 公里的高低差比一層列印還薄。2.22 mm for the Taiwan example. 600 km becomes 140 mm, so about 10 km of relief is thinner than one printed layer.
    2不能。垂直被誇大了約 10 倍，坡度只存在於模型，不存在於野外。No. Height is exaggerated about ten times, so the slope belongs to the model, not to the field.
    3線解析度提高 2.5 倍，三角形大約變成 6 倍。比噴嘴還密的細節印不出來，只會讓檔案變大、切片變慢。Linear resolution rises 2.5×, so the triangle count rises about 6×. Detail finer than the nozzle does not print; it only makes the file slower to slice.
    4看不到。02 角分大約 3–4 公里一格，32.8 公頃不到 1 平方公里。這份網格是區域地形，不是那 25 小時堆出來的火山灰。海溝是百萬年尺度，新陸地是小時尺度。No. A 2-arc-minute cell is about 3–4 km across, and 32.8 hectares is under 1 km². The grid is regional relief, not the ash piled up in those 25 hours. The trench is a million-year feature; the new land is an hours-long one.
